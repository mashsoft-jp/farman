# farman 0.9.7 の新機能

### プロパティダイアログを一新

ファイル / フォルダのプロパティを 1 つのダイアログに統合しました。

- 名前・場所・サイズ・更新日時・作成日時などをまとめて確認できます
- 複数選択時は合計サイズや個数を集計表示します
- 更新日時・属性 (パーミッション) をその場で編集できます
- 所有者 / グループは名前と ID を表示し、選択したファイルで共通のときだけ
  名前を変更できます (Windows では非表示)

### 「ビュアーで開く...」をプラグインから生成

「ビュアーで開く...」のメニューを、登録済みプラグインから自動生成する
ようにしました。これまで一覧に出なかった動画 / 音声ビュアーなども、
インストール済みのすべてのビュアーから選べます。

### 外部ビュアーにステータスバーを追加

別ウィンドウで開いたビュアーにも、内部表示と同じステータス情報を
表示するようにしました。動画ビュアーではフォーマット / コーデック /
解像度 / 再生時間の要約を表示します。

### その他の改善・修正

- Markdown ビュアーで、生 HTML を含む文書が途中で切れて表示される問題を
  修正しました
- ネットワーク / リムーバブルドライブ上のファイルは、ゴミ箱が使えないため
  「ゴミ箱へ移動」を無効化し、完全削除のみを選べるようにしました
- 長いファイル名のときに削除確認ダイアログのレイアウトが崩れる問題を
  修正しました
- 起動時の初期ディレクトリが存在しない場合に、ホーム / ルートへフォール
  バックするようにしました
- 0 バイトのファイルがバイナリビュアーで「読み込み中」のまま止まる問題を
  修正しました
- 安定性の改善とバグ修正
