# farman 1.1.0 の新機能

### プラグインをアプリ内でインストール

- 新しい **設定 → プラグイン** ページで、外部プラグインのインストール・更新・
  アンインストールをまとめて行えるようになりました。プラグインディレクトリへ
  手でファイルをコピーする必要はありません。
- プラグインのファイルをページにドラッグ＆ドロップするか、「ファイルから
  インストール...」で選ぶだけで導入できます。
- 公式プラグインは一覧から「インストール」「更新する」を押すだけで入手できます。
  「更新を確認」で最新版を調べ、更新があるプラグインは ❗ と太字で知らせます。
- インストール・更新・アンインストールは次回起動時に反映されます。ページの
  「farman を再起動」ボタンで、その場で再起動できます。
- ヘルプメニューの「プラグイン...」(Ctrl+Shift+P) やツールバーからも、このページを
  開けます。設定のページ番号は 4. プラグイン / 5. ビュアー / 6. アーカイブ … に
  変わりました。

### 起動時の TIPS

- 起動時に 1 日 1 回、使い方の TIPS を表示するようにしました。ショートカットや
  見落としがちな機能を 1 件ずつ紹介します。
- 「前へ」「次へ」で TIPS を順に見られます。本文のキーは、いまのキーバインドに
  合わせて表示します。
- ヘルプ → 「TIPS を表示...」からいつでも開けます。起動時に表示しない場合は、
  ダイアログ左下または 設定 → 全般 のチェックを外してください。

### ソートとフィルタ

- 「このディレクトリのデフォルトを上書きする」を付けずに一時的に変えた設定が、
  ダイアログを開き直すとデフォルトに戻って見えていたのを直しました。
- ダイアログを開いたとき、設定がデフォルトと違えば、保存済みか一時的かと、
  違う項目を表示します。
- 各ペイン下のソート・フィルタ表示の先頭に、いま効いている設定が
  **[デフォルト] / [一時的] / [カスタム]** (このディレクトリ用に保存したもの) の
  どれかを表示します。ドットファイルの扱い (ドット優先 / ドット無視) も表示します。
- 「ドットファイルを先頭にソート」をオフにすると、ドットファイルを先頭の「.」を
  除いた名前で並べるようにしました (.bashrc は b の位置に並びます)。

### 設定画面

- ビュアーの表示モード (メインウィンドウ内 / 別ウィンドウ) の設定を、「動作」から
  「ビュアー」ページへ移しました。
- 「全般」「動作」のチェックボックスを 2 列に並べ、見渡しやすくしました。

### ログペイン

- ログペインをクリックしてフォーカスを当てると、選択した文字列を Cmd+C (Windows /
  Linux では Ctrl+C) でクリップボードにコピーできるようになりました。Cmd+A (Ctrl+A)
  でログ全体を選択できます。

### 不具合修正

- UI を英語にしていても、検索結果のサイズ列の単位が OS の言語 (「36 バイト」など)
  で表示されていた問題を修正しました。
