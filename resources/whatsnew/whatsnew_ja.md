# farman 0.9.10 の新機能

（このバージョンは開発中です。内容は今後追加・変更される可能性があります。）

### 設定に「アーカイブ」タブを新設

- 対応しているアーカイブ形式を一覧で確認し、形式ごとに有効 / 無効を切り替えられる
  ようになりました。組み込み形式と、アーカイブプラグインが提供する形式を同じ一覧に
  並べています。
- 各形式の「詳細...」から、対象のファイルパターン、アーカイブ作成時の既定
  （圧縮レベル・暗号化方式・ファイル名の文字コード）を変更できます。作成できない
  形式では作成に関する設定は表示しません。
- 一時展開先、パスワードの入力回数、アーカイブ内アーカイブのネスト上限段数を
  まとめて設定できます。

### 対応アーカイブ形式を拡充

- 7-Zip / RAR / ISO9660 / Microsoft Cabinet / xar・pkg / cpio / ar・Debian
  パッケージ、TAR + Zstandard / LZ4 / LZMA / lzip / compress を一覧に追加しました。
- gzip / bzip2 / xz / LZMA / Zstandard / LZ4 / compress で圧縮した**単一ファイル**も、
  中身 1 件のアーカイブとして開けるようになりました。
- これらは既定では無効です。設定 → アーカイブで使いたい形式を有効にしてください。
  （お使いの環境の libarchive が対応していない形式は開けません）

### 設定画面の再編

- 「プラグイン」タブを廃止し、ビュアープラグインは新しい「ビュアー」タブ、
  アーカイブプラグインは「アーカイブ」タブで管理するようにしました。
- 外部プラグインの読み込み許可とプラグインディレクトリは「全般」タブに移しました。
- ビュアー・アーカイブとも、一覧のチェックボックスで直接、または「すべて有効」で
  まとめて切り替えられます。

### 対象ファイルの指定を「ファイルパターン」に統一

- ビュアーとアーカイブで呼び名と書式がばらばらだったのを揃えました。拡張子だけの
  従来の書き方に加えて、次のように書けます。
  - `mp4` … 拡張子（従来どおり）
  - `*.tar.gz` … 複合拡張子
  - `Makefile` … 拡張子を持たないファイル
- これまで設定で拡張子を増減してもビュアーの選択に反映されないことがありましたが、
  設定した内容がそのまま反映されるようになりました。

### ファイル一覧の操作

- 複数のファイルを選択した状態で「パスをコピー」すると、選択したすべてのパスを
  まとめてコピーするようになりました (これまではカーソル位置の 1 件だけでした)。
- パスではなく**ファイル名だけ**をコピーする操作を追加しました (既定のキーは
  Shift+Ctrl+C / macOS では Shift+Cmd+C)。
- まとめてコピーするときの区切りを設定できます (カンマ / カンマ+スペース /
  改行 LF・CRLF・CR)。設定 → 動作 → ファイル操作。
- コピー・移動・削除・リネームなどを実行すると、ステータスバーのパス表示位置に
  実行内容を数秒だけ表示するようになりました。表示時間は設定で変更でき、
  0 にすると表示しません。
- リネーム時に選択される範囲を変えました。ファイルは**最後の**ドットの手前まで
  ("photo.tar.gz" なら "photo.tar")、ディレクトリは名前全体を選択します
  (ディレクトリ名のドットに拡張子としての意味は無いため)。

### 不具合修正

- 英語版のアップデート内容ダイアログが途中で途切れる問題を修正しました。あわせて、
  Markdown 表示全般で同種の途切れが起きないようにしました。
- ビュアープラグインをすべて無効にしたとき、これまでバイナリビュアーだけが開いて
  いましたが、何も開かないようになりました。
