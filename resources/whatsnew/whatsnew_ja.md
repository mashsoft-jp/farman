# farman 0.9.8 の新機能

### アーカイブ外部プラグインに対応

ビュアー以外の外部プラグインを読み込める仕組みを追加しました。farman が
扱えるアーカイブ形式を、外部プラグインで後から増やせます。

- 追加した形式のアーカイブも、zip / tar と同じように中に入って
  ブラウジングでき、ファイルを取り出せます。
- プラグインは farman 本体には同梱せず、必要な方が別途ダウンロードして
  導入する形です。

### LZH (LHA) アーカイブ対応プラグインを公開

第一弾として、`.lzh` / `.lha` を開くための外部プラグインを別途公開しました。

- アーカイブの中に入ってのブラウジングと、ファイルの展開ができます
  (日本語 Shift-JIS のファイル名にも対応。読み取り専用)。
- お使いの OS 用のプラグインをダウンロードし、farman の外部プラグイン
  ディレクトリの `archives/` フォルダに置いて再起動すると有効になります。
  導入手順は README / 配布ページを参照してください。

### バイナリ / テキストビュアーの既定フォントを等幅に

バイナリビュアー (16 進ダンプ) とテキストビュアーの既定フォントを、確実に
等幅なフォントにしました (macOS = Menlo、Windows = MS ゴシック、
Linux = DejaVu Sans Mono)。桁がずれずに読めるようになります。

- これは新規インストール時の既定値です。すでに farman をお使いの場合は、
  設定ダイアログの各ビュアーの「フォント」で選び直すか「既定に戻す」で
  新しい既定フォントになります。

### Windows の既定フォントを調整

Windows では、UI 全般のフォントを **MS UI Gothic** にし、全体のフォントサイズを
**9pt** に統一しました (アドレスバー・ファイルリスト・各ビュアーは従来の
フォントのままサイズのみ 9pt)。新規インストール時の既定値です。
