# farman 0.9.6 の新機能

### 動画 / 音声ビュアーを追加

mp4 / mov / webm / mkv などの動画と、mp3 / flac / wav などの音声を
farman 内で直接再生できるようになりました (`V` キー)。
シーク / 音量 / ループ / フルスクリーンに対応しています。

### ビュアーのプラグイン化

同梱ビュアー (テキスト / 画像 / PDF / CSV / Markdown / バイナリ / メディア) を
動的ロードされる公式プラグインに移行しました。

- ユーザー作成の外部ビュアープラグイン (.dylib / .so / .dll) のロードに対応しました
- 拡張子ごとのビュアー関連付けが Inline 表示でも有効になりました

### 設定に「プラグイン」ページを追加

プラグイン関連の設定を 1 箇所に集約しました: ディレクトリ指定と、
種別ごとのタブに分けたインストール済みプラグインの一覧 (ロード状況と
有効 / 無効の切替)。各行の「詳細...」からプラグインの全情報を確認できます。
ヘルプ → プラグイン... (ツールバーボタン / ショートカットあり) からも
直接開けます。

### ビュアーの既定設定を「詳細」から変更

各ビュアーの既定設定を、プラグインの「詳細」内の設定ページで変更できる
ようになりました。対象拡張子の関連付けに加え、テキストの既定エンコード、
画像の Fit / ズーム、PDF の表示方法、CSV の区切り、メディアの音量・
自動再生 などを設定できます。同じ拡張子を複数のビュアーが対象にした
場合は、優先度の高いビュアーが使われます。

### HEIC / HEIF 画像の表示に対応

iPhone などで撮影した HEIC / HEIF 画像を画像ビュアーで表示できるように
なりました。macOS は OS 標準のデコーダ、Windows / Linux は同梱の libheif で
デコードします。

### アップデート内容の表示

アップデート後の初回起動時に、このダイアログでアップデート内容を
お知らせします。ヘルプ → アップデート内容... からいつでも再表示できます。

### その他

- 動画 / 音声ビュアーの対応形式を拡充しました (WMV / MPEG-1·2 / M2TS / WMA など)
- ディレクトリ比較の SHA-256 ハッシュ比較オプションを削除し、高速な既定比較に一本化しました
- 安定性の改善とバグ修正
