# farman 0.9.6 の新機能

### 動画 / 音声ビュアーを追加

mp4 / mov / webm / mkv などの動画と、mp3 / flac / wav などの音声を
farman 内で直接再生できるようになりました (`V` キー)。
シーク / 音量 / ループ / フルスクリーンに対応しています。

### ビュアーのプラグイン化

同梱ビュアー (テキスト / 画像 / PDF / CSV / Markdown / バイナリ / メディア) を
動的ロードされる公式プラグインに移行しました。

- ユーザー作成の外部ビュアープラグイン (.dylib / .so / .dll) のロードに対応しました
- 拡張子ごとのビュアー関連付けが Inline 表示でも有効になりました

### 設定に「プラグイン」ページを追加

プラグイン関連の設定を 1 箇所に集約しました: ディレクトリ指定、
インストール済みプラグインの一覧 (ロード状況) と有効 / 無効の切替、
ビュアーの拡張子関連付け。ヘルプ → プラグイン... (ツールバーボタン /
ショートカットあり) からも直接開けます。

### アップデート内容の表示

アップデート後の初回起動時に、このダイアログでアップデート内容を
お知らせします。ヘルプ → アップデート内容... からいつでも再表示できます。

### その他

- ディレクトリ比較の SHA-256 ハッシュ比較オプションを削除し、高速な既定比較に一本化しました
- 安定性の改善とバグ修正
