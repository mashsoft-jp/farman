# farman 1.0.1 の新機能

### コピー・移動の上書き確認

- 上書き確認ダイアログに**「以降の重複にもこの選択を適用する」**チェックボックス
  (Alt+A / macOS では ⌥A) を追加しました。オンにして OK すると、同じコピー・移動の
  残りの重複では確認せずに同じ選択 (上書き / 新しい名前 / スキップ) を使います。
  「新しい名前」を選んでいた場合、2 件目以降は自動リネームのテンプレートで
  名前を付けます。この記憶はその操作限りで、設定には保存しません。
- 「このファイルをスキップ」を選ぶと、これまでは操作全体が中止されていましたが、
  そのファイルだけを飛ばして続行するようになりました。飛ばしたファイルも
  進捗の件数に含め、100% で完了します。
- ダイアログのコピー元 / コピー先の表示位置を、見出しに揃えて読みやすくしました。

### ステータスバーのディスク容量

- ステータスバーのディスク容量を GiB 単位 (1024 ベース) の値で表示していたのを、
  GB 単位 (1000 ベース) で表示するよう修正しました。
  なお空き容量は OS が実際に空いていると報告する量で、macOS の「利用可能」に
  含まれる「削除可能」領域は含みません。

### 不具合修正

- ステータスバーのディスク使用率が「23%% 使用」のように % が二重に表示されて
  いた問題を修正しました。
- 検索ダイアログで、検索中や検索後に検索ボタンの「(⌥O)」表記が消えていた問題を
  修正しました。
- 表示メニューの「アクティブをパネルを反対側と同期」の誤字を修正しました。
