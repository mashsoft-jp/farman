# farman 1.2.0 の新機能

### Adobe Illustrator (.ai) の表示

- 画像ビュアーで Adobe Illustrator (.ai) を表示できるようになりました。PDF 互換の
  .ai の第 1 アートボードを、合成プレビューとして描画します。透明な部分は
  ほかの画像と同じく市松模様で表示します。
- 旧 EPS ベースの .ai や、「PDF 互換ファイルを作成」をオフにして保存した .ai は
  表示できません。
- 設定の画像ビュアーの対象ファイルに `ai` が自動で加わります。以前は .ai が
  PDF ビュアーで開かれていた場合も、これからは画像ビュアーで開きます。

### 画像ビュアー: 情報を右側のパネルに表示

- 「i」ボタン (または I キー) で開く画像の情報 (メタデータ) を、別ウィンドウではなく
  画像の右側のパネルに表示するようにしました。ファイルを切り替えると、パネルの
  内容も更新されます。境界をドラッグして幅を変えられます。

### PDF ビュアー: しおり (アウトライン) サイドバー

- しおりのある PDF では、ツールバーのしおりボタン (Cmd+Shift+B、Windows / Linux では
  Ctrl+Shift+B) で、左側にしおりの一覧を開けます。項目を選ぶと、そのページへ移動します。
- サイドバーを開くとフォーカスが移り、↑↓ キーで選んで Enter で移動できます。
  しおりのない PDF では、ボタンは使えません。

### Markdown ビュアー: 目次サイドバー

- ツールバーの目次ボタン (Cmd+Shift+B、Windows / Linux では Ctrl+Shift+B) で、
  見出しの一覧を左側に開けます。項目を選ぶと、本文がその見出しへスクロールします。
- 見出しの階層をそのまま表示します。見出しのない文書や、ソース表示のときは
  ボタンは使えません。

### ビュアーのツールバーをアイコンに

- Markdown・PDF・CSV・バイナリのビュアーで、文字だったツールバーのボタン
  (ソース表示・目次・しおり・ズーム・前後のページ・検索の前へ / 次へ など) を
  アイコンにしました。画像・メディアビュアーの「i」もアイコンになりました。
  割り当てているキーは、これまでどおりボタンにマウスを重ねると表示されます。

### 不具合修正

- Windows で、プラグインを更新して「farman を再起動」を押しても再起動しない問題を
  修正しました。
- Markdown ビュアーで、見出しから始まる文書をソース表示に切り替えると、全体が
  見出しのように太く大きく表示されていた問題を修正しました。
- PDF ビュアーの前後ページのボタンが、実際のキーと違う「PageUp / PageDown」を
  表示していたのを、割り当てているキーの表示に直しました。
