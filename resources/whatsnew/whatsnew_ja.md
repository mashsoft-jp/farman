# farman 0.9.9 の新機能

### 3D モデルビュアー（FBX）に対応

外部プラグイン **farman-plugin-3d** を導入すると、`.fbx` 形式の 3D モデルを
farman の中で表示できるようになりました。

- テクスチャ（外部・埋め込み）、スケルタルアニメーション、複数マテリアル、
  床グリッド、ワイヤーフレーム表示、ボーン（スケルトン）表示に対応しています。
- マウスやキーボードで回転・平行移動・拡大縮小ができます。
- プラグインは farman 本体には同梱していません。お使いの OS 用のものを別途
  ダウンロードし、外部プラグインディレクトリの `viewers/` フォルダに置いて、
  設定 → プラグインで「外部プラグインの読込みを許可する」をオンにして再起動
  すると有効になります。
- まず FBX に対応しました。今後 obj / glTF など他の形式にも広げていく予定です。

### ディレクトリサイズをサイズ列に表示（バックグラウンド算出）

- ファイル一覧で、ディレクトリの再帰合計サイズをバックグラウンドで算出して
  「サイズ」列に表示できるようになりました。
- あわせて、ディレクトリの「&lt;DIR&gt;」表示を（サイズ算出の有無に関わらず）
  つねに「種別」列に表示するようにしました。
- 既定はオフです。設定 → 動作 →「ディレクトリサイズ」で有効にできます。
- 算出方法は「毎回算出」か「一定時間キャッシュ」を選べ、キャッシュの保持時間も
  指定できます（ディレクトリの更新日時が変わると自動で再算出します）。
- ツールバーのボタン、または `Ctrl+Shift+R` で強制的に再算出できます。
- サイズ列が非表示のときは算出しません。

### バイナリビュアーの強化

- 表示を自前描画に作り替え、**ギガバイト級のファイル**でも全体を読み込まず表示中の
  行だけを読むようにしました。素早く開け、末尾まで正しく表示できます。
- 16 進アドレスへのジャンプに対応しました。入力欄の右に指定可能な最大アドレスを
  表示し、範囲外のアドレスは入力段階で受け付けません。
- 検索に対応しました。16 進 / 文字列をラジオボタンで切り替えられ、16 進検索は
  表示単位に合わせて入力できます（1 バイトなら「12 34 56」、2 バイトなら
  「1234 5678」。エンディアン反映）。Enter または 次へ / 前へ で前後に検索します。
  ヒットは 16 進側・文字列側の両方を反転表示します。ショートカット: 検索欄へ
  Cmd/Ctrl+F、次を検索 Cmd+G / F3、前を検索 Cmd+Shift+G / Shift+F3、アドレス欄へ
  Cmd/Ctrl+J、単位切替 Cmd/Ctrl+1〜4、エンディアン切替 Cmd/Ctrl+E。

### 不具合修正

- インラインビュアーからファイルリストに戻ったとき、一番下のファイルに合わせて
  いたカーソルがスクロールで隠れてしまうことがある問題を修正しました。
- 大きなファイルで末尾付近までスクロールしたあと、最終行が描画されないことが
  ある問題を修正しました。
