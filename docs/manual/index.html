farman マニュアル

基本操作からキーバインド、各機能の使い方まで。 下の検索ボックスにキーワードを入力すると、該当する項目だけに絞り込めます （例: コピー / アーカイブ / Ctrl+R）。

「」に一致する項目はありません。

基本操作

  • farman は左右にペインを並べるデュアルペインのファイラです。一方を「コピー元」、もう一方を「コピー先」として、ペイン間でファイルをやり取りします。
  • 操作対象はアクティブペイン（カーソルがある側）。Tab や左右キーの端でペインを切り替えます。
  • カーソル移動は ↑ ↓、ディレクトリに入るのは Enter、親ディレクトリへ戻るのは Backspace。
  • 選択は Space（選択して下へ）/ Shift+Space（移動なしで選択）。i で選択反転、Ctrl+A で全選択。
  • Shift+文字 で、その文字を頭文字とする次のファイルへカーソルジャンプ（連打で次の一致へ）。
  • レイアウトは デュアルペイン（2 画面）/ シングルペイン（1 画面）/ プレビュー の 3 種類。Ctrl+O でデュアル / シングルを切替、プレビューはツールバー / 設定から。（設定・コマンドでは「2 画面 / 1 画面」とも表記）
  • macOS では Ctrl は ⌘(Command) に割り当てられます。

表示モード・ペイン

  • 表示レイアウト: デュアルペイン（2 画面）/ シングルペイン（1 画面）/ プレビュー（Quick View） の 3 種類。Ctrl+O でデュアル / シングルを切替、プレビューはツールバー / 設定から。プレビューは片側でファイルを選ぶと、もう片側に内容を即表示します。（設定・コマンドでは「2 画面 / 1 画面」とも表記）
  • サムネイル表示: リスト / 小・中・大の 4 段階（Cmd/Ctrl+1〜4）。画像や PDF の 1 ページ目に対応。
  • ディレクトリ比較: 左右ペインの差分を行ごとに色分け。コピー後も比較状態を維持します。
  • 同期ブラウズ（y）: 片方のペインを移動すると、もう片方も相対的に追従します。
  • ディレクトリ同期（Ctrl+→ / Ctrl+←）: 一方のペインのパスを反対側に合わせます。
  • ソート・フィルタ（s）: ペインごとの並び順・表示フィルタを設定（このディレクトリ専用としても保存可）。
  • ログペイン（Ctrl+L）: 操作ログの表示切替。

キーバインド一覧（デフォルト）

すべて設定の「キーバインド」で変更できます（設定は Ctrl+,。ただし Tab と Shift+文字は固定）。macOS の Ctrl は ⌘。

ファイル操作

  • コピー / 移動（c / m）: 選択（無選択ならカーソル行）を反対ペインへ。確認ダイアログでコピー先・上書き時の挙動（都度確認 / 上書き / スキップ / リネーム）を指定できます。
  • 削除（d）: ゴミ箱に入れる / 完全削除を確認ダイアログで選べます。
  • リネーム（r）: カーソル行の名前を変更。
  • 一括リネーム（Ctrl+R）: テンプレート + 連番 + 正規表現置換に対応。適用前にプレビューで結果を確認できます。
  • 新規作成: k でディレクトリ、n でファイル。
  • パスのコピー（Ctrl+C）: カーソル / 選択ファイルの絶対パスをクリップボードへ（複数は改行区切り）。
  • プロパティ（a）: 名前・場所・サイズ・更新日時・作成日時をまとめて確認できる単一のダイアログ。更新日時やパーミッション（属性）はその場で編集できます。複数選択時は合計サイズと項目数を集計表示し、所有者 / グループは名前と ID を併記します（名前は選択ファイル間で共通のときだけ編集可、Windows では非表示）。
  • OS 既定アプリで開く（Shift+Enter またはダブルクリック）: 関連付けられたアプリでファイル / ディレクトリを開きます。

アーカイブ

  • 作成（p）: 選択ファイルを zip / tar / tar.gz / tar.bz2 / tar.xz で圧縮。圧縮レベルや zip の AES-256 パスワード暗号化を指定できます。
  • 展開（u）: カーソル位置のアーカイブを展開。暗号化 zip はパスワード入力で展開できます。
  • アーカイブ内ブラウジング: アーカイブを普通のフォルダのように開いて、中を移動・閲覧できます（パスは archive.zip!/inner/ のように表示されます）。必要なファイル / ディレクトリだけを選んで取り出す選択抽出もできます。

検索・ナビゲーション

  • ファイル検索（f）: バックグラウンドで再帰検索し、結果から直接ジャンプできます。
  • 即時フィルタ（/）: 現在のディレクトリの表示を、入力した文字で素早く絞り込みます。
  • ブックマーク: b で現在地を登録 / 解除、Ctrl+B で一覧。一覧には、登録したお気に入りに加え、マウント済みのドライブ（外部ディスク・ネットワークドライブ）が自動検出されて表示されます。
  • ディレクトリ履歴（h）: これまで開いたディレクトリの履歴から移動。
  • アドレスバー: パスを直接入力して移動（パス補完あり）。

設定

Ctrl+, で設定ダイアログを開きます。左側のカテゴリ（全般 / 動作 / 外観 / プラグイン / 外部アプリ / キーバインド）で各設定を切り替えます。各カテゴリの主な項目は次のとおりです。

  • 全般: 起動時の挙動・ウィンドウ・言語・ログなど、アプリ全体の基本設定。
    • 初期ディレクトリ: 起動時に開く場所を ホーム / 前回のセッション / 任意のパス から選択。左右ペインそれぞれに指定できます。
    • ウィンドウ: サイズと位置を デフォルト / 前回のセッション / カスタム で指定。
    • ログ: ログペインの表示（高さの指定）、ファイルへの出力（日付ごとのログを指定フォルダに保存、保持日数を過ぎたものは自動削除 / 無期限保持も選択可）。
    • 終了時の確認: アプリ終了時に確認ダイアログを表示するかどうか。
    • 二重起動の防止: farman を同時に複数起動させない（次回起動時に反映）。
    • ツールバーの表示: ツールバーの表示 / 非表示。
    • 言語: 自動（OS 追従）/ 英語 / 日本語。次回起動時に反映されます。
    • 自動アップデート: 1 日 1 回の自動チェック、確認なしでのダウンロード・インストール、「今すぐ確認」も可能。
    • バックアップ / 復元: 全設定（ブックマーク・カスタムコマンド・カラースキームを含む）を 1 つの JSON ファイルにエクスポート / インポートして他マシンへ移行できます。
  • 動作: ソート・ナビゲーション・ファイル操作・一覧表示の既定の挙動。
    • 既定のソート・フィルタ: ソートキー（第 1・第 2）と昇順 / 降順、ディレクトリの配置（先頭 / 末尾 / ファイルと混在）、ドットファイルを先頭に、大文字小文字の区別、隠しファイルを既定で表示。
    • ナビゲーション: カーソルの上下ループ、ディレクトリ履歴の永続化（次回起動時に復元）、Shift+文字 でドットファイルの 2 文字目にマッチ、同期ブラウズが自動解除されたときの通知。
    • ファイル操作: 削除時は既定でゴミ箱へ、自動リネームの接尾辞、検索時の除外ディレクトリ、完了時に進捗ダイアログを自動で閉じる。
    • 一覧表示: ファイルサイズの単位（バイト / KB / KiB / 自動）と桁区切り、日時の書式、一覧に表示するカラム。
    • ビュアー表示: ビュアーの表示方法（インライン / 別ウィンドウなど）の既定。
  • 外観: テーマ・配色・カーソル・行高など、見た目に関する設定。
    • 外観の設定は farman 本体の見た目（UI 全体・ファイルリスト・アドレスバーなど）に集約されました。各ビュアーのフォント・配色・画像の透過表示・対象拡張子は 設定 → プラグイン の各ビュアー設定へ移動しています（下記参照）。
    • テーマ: UI 全体の配色プリセット（ライト / ダーク、Auto は OS 追従）。
    • UI 全体: アプリ全体の基調色。
    • アドレスバー: アドレスバーの配色。
    • ファイルリスト: カテゴリ別のファイル色（選択中 / 非選択、アクティブ / 非アクティブ）、太字、行高。フォント種別・サイズ・行高はライト / ダーク共通、色とディレクトリの太字はテーマ別に設定できます。
    • カーソル / アクティブペイン: カーソルの見た目、アクティブな側の強調表示。
    • ディレクトリ比較: 差分行の配色。
  • プラグイン: インストール済みのビュアープラグインを種別タブで一覧表示します。各行の「詳細...」から、区分・プラグイン ID・パス・有効 / 無効・優先度・対象拡張子に加え、各ビュアーの表示設定（フォント・配色・画像の透過表示など）を確認・変更できます。フォント種別 / サイズはライト・ダーク共通、配色は各ページ内のライト / ダーク切替でテーマ別に編集できます（従来「外観」タブにあった各ビュアーの設定はここへ統合されました）。ユーザー作成の外部ビュアープラグイン（.dylib / .so / .dll）も、指定したプラグインディレクトリから読み込めます。
  • 外部アプリ: ターミナル（t）・エディタ（e）などの起動コマンドを登録。プレースホルダで現在のパスや選択ファイルを渡せます。
  • キーバインド: すべてのショートカットを変更可能。デフォルトに戻す、Total Commander 風などのプリセット選択、割り当て解除もできます。

設定ファイルの場所: macOS ~/Library/Preferences/Farman/farman/settings.json / Linux ~/.config/Farman/farman/settings.json / Windows %APPDATA%\Farman\farman\settings.json

同梱公式ビュアー

v でビュアー起動、Ctrl+Enter でビュアーを選択。インライン表示 / 別ウィンドウのどちらにも対応し、全文検索が使えます。

テキスト

対応形式: txt, log, c / cpp / h, py, js, ts, java, json, xml, yml, ini, sh / bash / fish など

主な機能: 文字エンコード自動判定、行番号、ワードラップ、全文検索

画像

対応形式: png, jpg, jpeg, gif, bmp, svg, webp, ico, tiff, tif, psd, heic, heif

主な機能: ズーム / Fit、透明背景チェッカー、GIF・WebP アニメ、90° 回転、Info（Exif・ICC・DPI）、PSD 合成プレビュー

動画 / 音声

対応形式: 動画: mp4, mov, webm, mkv, avi, wmv, mpeg, m2ts, ts など／音声: mp3, flac, wav, aac, ogg, wma など

主な機能: 再生、シーク（バーのクリックでその位置へ即移動）、音量、ループ、フルスクリーン、動画のズーム / ウィンドウにフィット、Info（メタデータ / 形式・コーデック・解像度・長さ）

Markdown

対応形式: md, markdown, mdown, mkd

主な機能: 整形プレビュー / ソース表示の切替、表・タスクリスト、全文検索

PDF

対応形式: pdf

主な機能: ページ送り、ズーム / Fit、全文検索

CSV・TSV

対応形式: csv, tsv

主な機能: 区切り自動判定、セル検索、先頭行をヘッダ扱い、巨大ファイルの遅延ロード

バイナリ

対応形式: 上記いずれにも該当しない任意のファイル

主な機能: 16 進ダンプ（アドレス列・文字列列のカラーリング）

各ビュアーの既定設定（対象拡張子、表示方法など）は 設定 → プラグイン で対象のビュアーを選び 「詳細」 を開いて変更できます（テキストの既定エンコード、画像の Fit / ズーム、PDF の表示方法、CSV の区切り、メディアの音量・自動再生 など）。

拡張子の対応付けについて: 同じ拡張子を複数のビュアーが対象にしている場合、優先度の高いビュアーが選ばれます（各ビュアーが宣言する対応拡張子の中から優先度で解決）。特定の拡張子を必ず特定のビュアーに固定する「先勝ち」の上書き指定はありません。狙いどおりに開かない場合は、優先したいビュアー側に拡張子を追加し、競合する側からは外してください。

インストールと更新

  • ダウンロード: トップページのダウンロード または GitHub Releases から。各アセットに .sha256 チェックサム付き。
  • macOS: Apple Silicon (arm64) 向け .dmg。Developer ID 署名 + 公証済みで、Gatekeeper 警告なしに起動できます。
  • Windows: インストーラ .exe またはポータブル .zip（x64）。現状コード署名は未対応です。
  • Linux: .AppImage または .deb（x86_64）。
  • 自動アップデート: 起動時に新版をチェックし、ワンクリックでダウンロード + SHA256 検証 + インストール。
  • アップデート内容の表示: アップデート後の初回起動時に変更内容をダイアログで表示します。ヘルプ → アップデート内容... からいつでも再表示できます。

この内容は farman の最新版に基づいています。キーバインドは初期設定（Default）の値です。 不明点や記載の誤りは GitHub Issues へ。
