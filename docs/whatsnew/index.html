更新情報

バージョンごとの更新情報です。アプリの「ヘルプ → アップデート内容...」で表示される内容と同じものを、最新版から順に掲載しています。

farman 0.9.8 2026-07-23

アーカイブ外部プラグインに対応

ビュアー以外の外部プラグインを読み込める仕組みを追加しました。farman が扱えるアーカイブ形式を、外部プラグインで後から増やせます。第三者が作成したプラグインも導入できます。

  • 追加した形式のアーカイブも、zip / tar と同じように中に入ってブラウジングでき、ファイルを取り出せます。
  • プラグインは farman 本体には同梱せず、必要な方が別途ダウンロードして導入する形です。

外部プラグインの読込みは明示的な許可制に

外部プラグインはネイティブコードで、farman と同じ権限で動作します。安全のため、外部プラグインの読込みは既定で オフ にしました。

  • 設定 → プラグイン の 「外部プラグインの読込みを許可する」 をオンにすると、外部プラグインディレクトリのプラグインを次回起動時から読み込みます（同梱プラグインは常に有効）。
  • 信頼できる提供元のプラグインだけを有効にしてください。

LZH (LHA) アーカイブ対応プラグインを公開

第一弾として、.lzh / .lha を開くための外部プラグインを別途公開しました。

  • アーカイブの中に入ってのブラウジングと、ファイルの展開ができます（日本語 Shift-JIS のファイル名にも対応。読み取り専用）。
  • お使いの OS 用のプラグインをダウンロードし、farman の外部プラグインディレクトリの archives/ フォルダに置き、設定 → プラグインで「外部プラグインの読込みを許可する」をオンにして再起動すると有効になります。導入手順は プラグインページを参照してください。

バイナリ / テキストビュアーの既定フォントを等幅に

バイナリビュアー (16 進ダンプ) とテキストビュアーの既定フォントを、確実に等幅なフォントにしました（macOS = Menlo、Windows = MS ゴシック、Linux = DejaVu Sans Mono）。桁がずれずに読めるようになります。

  • これは新規インストール時の既定値です。すでに farman をお使いの場合は、設定ダイアログの各ビュアーの「フォント」で選び直すか「既定に戻す」で新しい既定フォントになります。

Windows の既定フォントを調整

Windows では、UI 全般のフォントを MS UI Gothic にし、全体のフォントサイズを 9pt に統一しました（アドレスバー・ファイルリスト・各ビュアーは従来のフォントのままサイズのみ 9pt）。新規インストール時の既定値です。

動画ビュアーのフルスクリーンを改善

動画のフルスクリーンが正常に動作しない問題（全画面に拡大されない・Esc で戻れない）を修正しました。あわせて、フルスクリーン中にマウスを動かすと画面下部に半透明の操作パネル（再生/一時停止・停止・シーク・リピート・音量）を表示するようにしました。

その他

  • ウィンドウをドラッグでリサイズ中に「幅 × 高さ」を表示
  • ファイルリストの「名前」列がウィンドウ幅に合わせて伸縮するように変更
  • macOS: 漢字ラベルのボタンだけ形状が違って見える問題を修正
  • Windows: zip / lzh 内の Shift-JIS (CP932) の日本語ファイル名が文字化けする問題を修正
  • 安定性の改善とバグ修正

farman 0.9.7 2026-07-08

プロパティダイアログを一新

ファイル / フォルダのプロパティを 1 つのダイアログに統合しました。

  • 名前・場所・サイズ・更新日時・作成日時などをまとめて確認できます
  • 複数選択時は合計サイズや個数を集計表示します
  • 更新日時・属性 (パーミッション) をその場で編集できます
  • 所有者 / グループは名前と ID を表示し、選択したファイルで共通のときだけ名前を変更できます (Windows では非表示)

「ビュアーで開く...」をプラグインから生成

「ビュアーで開く...」のメニューを、登録済みプラグインから自動生成するようにしました。これまで一覧に出なかった動画 / 音声ビュアーなども、インストール済みのすべてのビュアーから選べます。

外部ビュアーにステータスバーを追加

別ウィンドウで開いたビュアーにも、内部表示と同じステータス情報を表示するようにしました。動画ビュアーではフォーマット / コーデック / 解像度 / 再生時間の要約を表示します。

その他の改善・修正

  • Markdown ビュアーで、生 HTML を含む文書が途中で切れて表示される問題を修正しました
  • ネットワーク / リムーバブルドライブ上のファイルは、ゴミ箱が使えないため「ゴミ箱へ移動」を無効化し、完全削除のみを選べるようにしました
  • 長いファイル名のときに削除確認ダイアログのレイアウトが崩れる問題を修正しました
  • 起動時の初期ディレクトリが存在しない場合に、ホーム / ルートへフォールバックするようにしました
  • 0 バイトのファイルがバイナリビュアーで「読み込み中」のまま止まる問題を修正しました
  • 安定性の改善とバグ修正

farman 0.9.6 2026-06-24

動画 / 音声ビュアーを追加

mp4 / mov / webm / mkv などの動画と、mp3 / flac / wav などの音声を farman 内で直接再生できるようになりました (V キー)。シーク / 音量 / ループ / フルスクリーンに対応しています。

ビュアーのプラグイン化

同梱ビュアー (テキスト / 画像 / PDF / CSV / Markdown / バイナリ / メディア) を動的ロードされる公式プラグインに移行しました。

  • ユーザー作成の外部ビュアープラグイン (.dylib / .so / .dll) のロードに対応しました
  • 拡張子ごとのビュアー関連付けが Inline 表示でも有効になりました

設定に「プラグイン」ページを追加

プラグイン関連の設定を 1 箇所に集約しました: ディレクトリ指定、インストール済みプラグインの一覧 (ロード状況) と有効 / 無効の切替、ビュアーの拡張子関連付け。ヘルプ → プラグイン... (ツールバーボタン / ショートカットあり) からも直接開けます。

アップデート内容の表示

アップデート後の初回起動時に、このダイアログでアップデート内容をお知らせします。ヘルプ → アップデート内容... からいつでも再表示できます。

その他

  • ディレクトリ比較の SHA-256 ハッシュ比較オプションを削除し、高速な既定比較に一本化しました
  • 安定性の改善とバグ修正

farman 0.9.5 以前の変更内容は、GitHub Releases を参照してください。
